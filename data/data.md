# Synthetic Retinotopy Dataset

Generated by `generate_data.py` using `config.yaml`.

---

## What this data represents

Each of the 17,263 nodes is one spot on the visual cortex. For each node we know:
- which spot in the visual field it is responsible for (ground truth — because we built it that way)
- how strongly it responds to 100 simulated visual stimuli (the synthetic fMRI signal)

The GNN gets the response signals as input and must predict the visual field positions.

---

## File 1 — `retinotopy_groundtruth.pt`

Load with:
```python
ckpt = torch.load('data/retinotopy_groundtruth.pt', map_location='cpu')
data = ckpt['data']
```

| Field | What it contains | Shape | Values |
|-------|-----------------|-------|--------|
| `data.x` | **Model input.** pRF responses: how each node responds to each of the 100 stimuli. This is the synthetic fMRI signal. | `(17263, 100)` | ~0 … 1 |
| `data.y` | **Prediction target.** `[eccentricity, polar_angle]` per node. Column 0 = eccentricity in degrees, column 1 = polar angle in radians. | `(17263, 2)` | ecc: 0.1–12°, angle: −π … π |
| `data.edge_index` | Which nodes are connected. Row 0 = source node, row 1 = target node. Each undirected edge appears twice (both directions). | `(2, 102432)` | node indices |
| `data.edge_attr` | Euclidean edge weights: straight-line distance in mm between two connected nodes. This is the **κ=0 baseline**. | `(102432,)` | 0.24–1.64 mm |
| `data.pos` | 3D brain coordinates of each node (MNI space, in mm). | `(17263, 3)` | brain coords |
| `data.eccentricity_gt` | Ground-truth eccentricity per node (same as `data.y[:, 0]`, stored separately for convenience). | `(17263,)` | 0.1–12° |
| `data.polar_angle_gt` | Ground-truth polar angle per node (same as `data.y[:, 1]`). | `(17263,)` | −π … π |
| `data.magnification` | Cortical magnification factor: mm² of cortex per deg² of visual field. High near fovea, low at periphery. Not a training target — useful for analysis. | `(17263,)` | 0.78–1.88 |
| `data.train_mask` | Boolean mask: which nodes to train on (70%, ~12,084 nodes). | `(17263,)` | bool |
| `data.val_mask` | Boolean mask: which nodes to use for validation (15%, ~2,589 nodes). | `(17263,)` | bool |
| `data.test_mask` | Boolean mask: which nodes to use for final evaluation (15%, ~2,590 nodes). | `(17263,)` | bool |

**Note on data leakage:** `eccentricity` and `polar_angle` are intentionally **not** included in `data.x`. If they were, the model would see the answers it's supposed to predict. The model must learn purely from the pRF response pattern.

## File 2 — `curved_metrics_kappa.pt`

Load with:
```python
hyp = torch.load('data/curved_metrics_kappa.pt', map_location='cpu')['kappa_metrics']
```

Keyed by κ (float). For each κ value in `config.yaml → hyperbolic → kappa_values`:

| Field | What it contains | Shape |
|-------|-----------------|-------|
| `hyp[κ]['edge_attr']` | Hyperbolic edge weights. Drop-in replacement for `data.edge_attr`. Same shape, bidirectional. | `(102432,)` |
| `hyp[κ]['dist_to_pole']` | Hyperbolic distance from each node to the foveal pole. Can be appended as an extra column to `data.x`. | `(17263,)` |

`κ=0.0` gives identical values to the Euclidean baseline.

**How to use κ in training:**
```python
# Euclidean baseline (κ=0)
data.edge_attr  # already set in groundtruth file

# Hyperbolic experiment (e.g. κ=0.1)
data.edge_attr = hyp[0.1]['edge_attr']                       # Marla option 2
# or: append hyp[0.1]['dist_to_pole'] as extra node feature  # Marla option 1
```

## How the data was generated (short version)

1. Load the fsaverage brain surface (163,842 vertices)
2. Keep only the visual cortex (y < −70mm → 17,263 vertices)
3. Find the occipital pole (most posterior vertex) = the fovea representation
4. Compute polar angle: compass direction of each node around the pole (x-z plane)
5. Build the graph: mesh triangles → edges with Euclidean weights
6. Run Dijkstra from the pole to get surface distances for all nodes
7. Convert surface distance → eccentricity via the log-polar magnification formula
8. Simulate 100 pRF responses (Gaussian tuning curves) per node
9. Compute hyperbolic edge weights for each κ value
10. Save + generate train/val/test masks (70/15/15 split)
